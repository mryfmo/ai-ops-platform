# Spec ID Catalog

This catalog defines the newer IDs added around T05-T15. Older IDs (`REQ-001` through `REQ-035`, older `SPEC-*`, `TH-*`, and AC IDs) remain governed by the original PrjOps/DevOps source documents and are only indexed in `packages/traceability/spec-ids/*.json`.

Spec IDs are namespaced by system plus ID string. The same number can exist in both PrjOps and DevOps.
