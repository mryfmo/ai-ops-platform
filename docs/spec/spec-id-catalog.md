# Spec ID Catalog

This file is the repository-local catalog for every ID indexed by `packages/traceability/spec-ids/*.json`.
The linked canonical source span is normative. The Definition cell is a review aid transcribed from that span with Markdown presentation normalized for one table cell; literal table separators are encoded as `&#124;`. The automated gate validates the primary-definition anchor, not textual or semantic equality.
The system name is part of the canonical ID. A PrjOps row never defines the same bare ID for DevOps, or vice versa.

`mise run traceability` fails when an indexed ID is missing, duplicated, placed under the wrong system, lacks a definition, or links to a missing canonical source.
The gate proves reference presence and catalog integrity only. It does not prove that implementation behavior satisfies a requirement or acceptance criterion.
