## 1. 現行業務の全体像

現行のPrjOps業務は、PMOスタッフ（2〜4名を想定）が中心となり、週次サイクルで「収集 → 集計 → 分析 → 報告 → フォロー」を回す運用である。情報の入口はメール（Outlook）、Teams投稿、会議での口頭報告、Excel台帳に分散しており、正本が一意に定まっていない。

## 3. 関係者の役割と意思決定ポイント

| 関係者（対応プロファイル） | 現行の役割 | 意思決定ポイント |
|---|---|---|
| 実務担当者（PRF-01） | 進捗・課題の一次報告 | なし（報告のみ） |
| PM／リーダー（PRF-02） | 自プロジェクトの進捗判断・報告承認 | DP-1: 自プロジェクトのステータス色（順調/注意/危険）の判定 |
| PMOスタッフ | 収集・集計・資料作成・督促 | なし（作業のみ、判断はエスカレーション） |
| マネージャー／PMO責任者（PRF-03） | 横断課題の裁定、経営報告の承認 | DP-2: 課題のエスカレーション要否、DP-3: 経営陣へ報告する内容の承認 |
| 経営陣（PRF-04） | ポートフォリオ判断（継続/中止/リソース再配分） | DP-4: プロジェクト継続・投資判断 |
| 投資元（PRF-05） | 報告の受領・質問 | なし（閲覧・質疑のみ） |

## 4. 情報の流れ（AS-IS）

```
各社担当者(PRF-01) --メール/Teams/口頭--> PM(PRF-02) --メール/Excel--> PMOスタッフ
PMOスタッフ --手作業転記--> 進捗集計Excel --手作業整形--> 階層別資料(PowerPoint等)
PMOスタッフ --メール添付--> リーダー/マネージャー/経営陣/投資元（それぞれ別資料を個別送付）
```

- 正本が「進捗集計Excel」「課題管理Excel」「各PMの手元資料」に分散し、版ズレが常態化している。
- 海外企業とのやり取りは時差（例: 欧州-8h、米国西海岸-16h）により1往復に1〜2営業日を要する。

## 5. 現状の課題（ISS-xxx）

各課題には定量的な影響の目安（標準参照モデルにおける推定値。実測値は貴組織で要確認）を付す。

| ID | 課題 | 影響（推定） | 関連プロセス |
|---|---|---|---|
| ISS-001 | 進捗収集・転記が手作業で、集計完了まで依頼から2〜3営業日かかる | 週次サイクルの約半分が収集に消費される | PROC-01, 02, 03 |
| ISS-002 | 転記ミス・版ズレにより報告数値の不整合が発生する | 月1回程度の差し戻し・再作成 | PROC-02, 03, 05 |
| ISS-003 | 階層別資料の作り分けが属人的で、粒度・書式が毎回ばらつく | 資料作成にPMOスタッフ延べ2〜3人日/週 | PROC-05, 09 |
| ISS-004 | 課題・アクションの期限管理が人の記憶と目視に依存し、フォロー漏れが発生する | 期限超過アクションの検知遅れ（平均3〜5営業日） | PROC-04, 07 |
| ISS-005 | 海外企業との連絡が時差・言語で遅延し、週次サイクルに乗らない案件がある | 海外案件の報告が1週遅れで混入 | PROC-08 |
| ISS-006 | 50件規模に対しPMO人員が線形にしか増やせず、件数増に耐えられない | 1人あたり12〜25件の担当が限界 | 全体 |
| ISS-007 | 報告の履歴・根拠（誰がいつ何を報告したか）が監査可能な形で残らない | 監査・投資元質疑への回答に都度調査が必要 | PROC-02, 09 |
| ISS-008 | 経営陣・投資元向け報告が月次/四半期の手作業で、鮮度が低い | 意思決定が最大1か月前の情報に基づく | PROC-09 |
| ISS-009 | ステータス色（順調/注意/危険）の判定基準が各PMの主観でばらつく | ポートフォリオ横断比較が困難 | PROC-03, DP-1 |
| ISS-010 | テンプレート・手順が更新されても周知が徹底されず旧版が使われ続ける | 収集データ形式の不統一 | PROC-10 |
