## 2. システム名と対象

- 本プロジェクトで構築するシステムを「**PrjOps AI基盤**」（英名: PrjOps AI Hub、以下「本システム」）と呼ぶ。
- 対象業務: プロジェクト運営管理（PrjOps）。対象規模: プロジェクト約50件（設計上限100件）、関連企業 国内外 数十社（設計上限100社）。

## 6. ID体系

- 要件: `REQ-nnn`（DOC-03）／外部仕様: `SPEC-EXT-nnn`（DOC-04）／内部仕様: `SPEC-INT-nnn`（DOC-05）
- 現状課題: `ISS-nnn`（DOC-01）／将来プロセス: `TOBE-nnn`（DOC-02）／仮定: `ASM-nnn`（本書§7）
- 環境表: 開発 `DEV-nn`（DOC-06）／運用 `OPS-nn`（DOC-07）
- IDは一度付与したら欠番があっても再利用しない。

## 8. 用語集（抜粋・全文書で同一の意味で使用）

- **進捗アップデート（status_update）**: 1プロジェクト×1報告期間の進捗データ1件。スキーマはSPEC-INT-020。
- **レポートジョブ（report_job)**: 1配信サイクルで生成されるプロファイル別レポート生成タスクの単位。
- **エスカレーション**: 定義された条件（期限超過・承認未応答・検証NG）で上位者へ通知を上げる処理。条件は各SPEC-INTに数値で明記。
- **HITL（Human in the Loop）**: 人間の承認・判断をワークフローに挟むこと。本システムの承認ゲートはSPEC-EXT-024に列挙。
