## 重要な留意点

1. **AUD-OPM-001（Critical）と T-P0-13/14 は相互依存して停止している。** 承認フロー系が旧監査の Critical・High のまま生き残っており、これが「人間が承認し、エージェントが実行する」という本システムの中心哲学の未完部分にあたる。
2. **是正作業は `87b7039`（PR #118 マージ）以前で止まっている。** main の直近コミット群（`631fcef` 〜 上位 14 件）はすべて .pptx / .zip / .md の追加・削除で、コード変更を伴わない資料アップロードである。P0 の残り 5 件が動いた形跡はない。
3. **AUD-SEC-002 と AUD-TRC-002 は「最小是正のみ・恒久策未着手」という同型パターン。** 文書化により severity を下げたと主張できる一方、技術的リスクは残存している。この型の是正を「解消」と数えないことが重要。
4. **`docs/audit/09-remediation-plan.md` の進捗表は実態より遅れている。** T-P0-10 は未チェックのままだが実コードでは完了済み。この表を根拠に判断すると誤る。
5. 旧監査 68 所見のうち本章で判定したのは Critical 6 + High サンプル 8 + P0 14 件。残る Medium/Low は今回の対象外だが、01〜05 章の新規所見が実質的に重複範囲をカバーしている。
