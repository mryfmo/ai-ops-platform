# Dashboard Guide

## ログイン

ダッシュボードは `/app/dashboard` で開く。未ログインの場合は `/app/login` に移動する。認証は Auth.js + Microsoft Entra ID を使う。

ログイン後、メールアドレスからペルソナを解決する。複数ペルソナを持つ場合、現実装では先頭のペルソナを使う。切替 UI はまだない。

## 見える画面

| ペルソナ        | 初期表示/表示できるもの                                                                                                             |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| PrjOps `PRF-04` | 経営ダッシュボード（Seven Keys）。ページエージェントから Seven Keys、プロジェクト一覧、時系列を表示できる。                         |
| PrjOps `PRF-03` | マネージャーダッシュボード。ページエージェントからバーンダウン/DORA相当のマネージャービュー、プロジェクト一覧、時系列を表示できる。 |
| DevOps `PRF-G`  | マネージャーダッシュボード。ページエージェントから AI コーディングエージェント稼働状況も表示できる。                                |
| Investor        | Investor Report。ページエージェントから投資家 KPI、プロジェクト一覧、時系列を表示できる。                                           |

## 期間切替

画面上部の「表示期間」で `week` / `month` / `quarter` / `half` / `year` を選ぶ。`前へ` / `次へ` は現在の期間単位で基準日を移動する。

期間を変えると、現在のビューを再取得し、時系列パネルも表示する。時系列パネルには Open、Close、遷移、Milestone、Deploy の合計が出る。

## ページエージェント

右側のチャットに、見たい画面を自然文で入力する。チャットは数値そのものを本文で作らず、表示切替 tool を呼ぶ。

Tool の結果が出ると、カードに `ページに固定` ボタンが表示される。押すと、その ViewSpec に対応する `/app/api/data/*` を取得して画面へ固定する。

推論パートがある場合は「推論」として折りたたみ表示される。

## いま実装されていないこと

- ペルソナ切替 UI。
- PrjOps production data provider。現状の Web route は空の in-memory provider を使う箇所がある。
- 認証済みの実DB/実LLM/実Webhookを含む E2E はローカルだけでは完了しない。実環境手順は [runbook](../../runbooks/e2e-real-environment.md) を参照する。
