# Owner 署名用裁定: P8-T03 credential lifecycle amendment（2026-08-17）

- 裁定者: Owner（@mryfmo）
- 状態: Proposed（本記録を含む PR の Owner merge をもって Accepted / 発効）
- 対象: WBS P8-T03（Issue scoped LiteLLM runner credentials）
- 根拠: `docs/security/2026-08-10-secret-identity-migration-plan.md` の
  `Required WBS ownership decisions`

## Amendment

P8-T03 の deliverables、acceptance、verification、allowed paths を次のとおり
binding に改訂する。

1. LiteLLM virtual key に加え、GitHub App installation token も job ごとに
   mint/use/revoke する。installation token は対象 repository と最小 permission に限定し、
   push/PR 専用 step にだけ注入する。
2. workflow から control-plane issuer への認証には GitHub OIDC の
   audience-bound token を使う。runner は LiteLLM master key、provider key、
   GitHub App private key を一切保持しない。live endpoint 未到達時は構造検証を先行し、
   endpoint 設定不在、OIDC token 不在、audience 不一致を fail closed とする。
3. LiteLLM virtual key と installation token は runner の成功・失敗にかかわらず
   always-run cleanup で revoke し、revoke failure を握り潰さない。有限 expiry は
   cleanup 漏れへの defense in depth とする。
4. verification に out-of-scope repository、main push、期限切れ key、cleanup failure、
   master/provider/private-key 非流出の負テストを含める。そのため
   `packages/control-plane/tests/**` を allowed paths に追加する。
5. P8-T03 は `AIOPS_PR_TOKEN` 依存を除去できる readiness までを証明する。
   repository secret の最終削除は従来どおり P10-T10 が所有する。

## 署名と発効

本記録を含む amendment PR を Owner が merge した事実を GOV-003 署名とする。
merge 前は P8-T03 implementation を凍結し、merge 後にのみ改訂済み WBS の範囲で
実装を再開できる。AI agent の commit、push、PR 作成、review は署名を代替しない。

## 効果

- credential issuer root は control-plane / LiteLLM / GitHub App 側に留まり、runner へは
  job-scoped derived credential だけが渡る。
- P8-T03 の verification と allowed paths の不整合が解消される。
- PAT の最終削除 ownership と environment-gated E2E は後続 gate のまま維持される。
