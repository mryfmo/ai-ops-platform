# HTTP API Reference

## Server: Hono routes

These routes are registered by [`packages/server/src/http/app.ts`](../../packages/server/src/http/app.ts).

| Method | Path                                      | Auth                                                                          | Request                                                         | Response / Errors                                                                                                                                                                 |
| ------ | ----------------------------------------- | ----------------------------------------------------------------------------- | --------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET`  | `/healthz`                                | None                                                                          | None                                                            | `200 { ok: true }`.                                                                                                                                                               |
| `GET`  | `/readyz`                                 | None                                                                          | None                                                            | `200 { ready: true }` or `503 { ready: false }` if readiness throws or returns false.                                                                                             |
| `GET`  | `/metrics`                                | Exact `Authorization: Bearer <METRICS_TOKEN>` when configured; none otherwise | None                                                            | Prometheus text metrics for queue depth, task duration/failures, and report delivery outcomes. Invalid or missing configured token returns `401` with `WWW-Authenticate: Bearer`. |
| `POST` | `/webhooks/graph?validationToken=...`     | Graph validation token handshake                                              | Empty body allowed for handshake                                | `200 text/plain` with the token.                                                                                                                                                  |
| `POST` | `/webhooks/graph`                         | `clientState` in notification body                                            | Microsoft Graph notification JSON                               | `202` after accepted notifications are enqueued; bad JSON returns `400`. Rejected clientState is audited and still returns `202`.                                                 |
| `POST` | `/webhooks/github`                        | `X-Hub-Signature-256` HMAC using `GITHUB_WEBHOOK_SECRET`                      | Raw GitHub webhook JSON                                         | `202` after enqueue; invalid signature `401`; invalid JSON `400`.                                                                                                                 |
| `POST` | `/reports/ingest`                         | `x-aiops-signature-256` HMAC using `REPORT_INGEST_SECRET`                     | Standard `report.json`                                          | Stores and optionally delivers a valid report. Invalid signature `401`, invalid schema `422`, disabled config `503`.                                                              |
| `GET`  | `/coding-tasks/:taskId/confirm?token=...` | HMAC confirm token                                                            | None                                                            | HTML confirmation page; invalid token `403`, missing task `404`.                                                                                                                  |
| `POST` | `/coding-tasks/:taskId/confirm`           | HMAC confirm token in form/json body                                          | `token`                                                         | Starts `coding-task.yml` workflow after explicit human confirmation; unregistered repo returns `409`.                                                                             |
| `POST` | `/internal/coding-tasks/:taskId/callback` | Bearer `CODING_TASK_CALLBACK_SECRET`                                          | JSON with `status`, optional `prUrl`, `branch`, `workflowRunId` | Updates task status; unauthorized `401`, invalid JSON/status `400`, missing task `404`.                                                                                           |
| `GET`  | `/xlsx-import/template`                   | Empty-body HMAC using `XLSX_IMPORT_SECRET`                                    | None                                                            | Internal template source for WebUI; missing or invalid HMAC returns `401`.                                                                                                        |
| `POST` | `/xlsx-import/dry-run`                    | `x-aiops-signature-256: sha256=<HMAC>` using `XLSX_IMPORT_SECRET`             | Raw `.xlsx` body, maximum 10 MiB                                | `200 { ok, rowCount, errors, summary }`; invalid HMAC `401`, oversized body `413`, disabled config `503`.                                                                         |
| `POST` | `/xlsx-import/execute?owner=&repo=`       | Same HMAC header plus `x-confirm-import: yes`                                 | Raw `.xlsx` body, maximum 10 MiB                                | Writes GitHub objects; invalid template/query `400`, repo outside allowlist `403`, missing confirmation `409`, oversized body `413`.                                              |
| any    | `/app/*`                                  | WebUI handles auth under proxied app                                          | Proxied request                                                 | Proxies to Next.js at `WEBUI_INTERNAL_PORT`; no upstream config `503`, unreachable upstream `502`.                                                                                |

## Web: Next.js API routes

The Web app runs under base path `/app`, so the public route prefix is `/app/api`.

| Method        | Path                              | Auth                                                | Query / Body                                                                                                      | Response / Errors                                                                                                                                               |
| ------------- | --------------------------------- | --------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GET`, `POST` | `/app/api/auth/*`                 | Auth.js                                             | Auth.js protocol requests                                                                                         | Auth.js Microsoft Entra ID sign-in, callback, session, and sign-out handlers.                                                                                   |
| `GET`         | `/app/api/health`                 | None                                                | None                                                                                                              | `{ ok: true }` if workspace modules load.                                                                                                                       |
| `POST`        | `/app/api/persona`                | Auth.js session + same-origin check                 | `{ persona: "<domain>:<profile>" }`; value must be one of the current account's resolved personas                 | `200 { selectedPersona }` and an HttpOnly `/app` cookie. Invalid body `400`, invalid origin or unassigned persona `403`, missing session `401`.                 |
| `GET`         | `/app/api/xlsx-import/template`   | Auth.js session                                     | None                                                                                                              | Downloads the current Excel template through the HMAC-authenticated internal server route. Disabled config `503`, upstream unavailable `502`.                   |
| `POST`        | `/app/api/xlsx-import`            | Auth.js session + same-origin check                 | Raw `.xlsx`; `operation=dry-run\|execute`; execute also requires `owner`, `repo`, and `x-confirm-import: yes`     | HMAC-signs exact raw bytes server-side; maximum 10 MiB. Invalid operation/query `400`, invalid origin `403`, missing confirmation `409`, disabled config `503`. |
| `GET`         | `/app/api/data/executive-summary` | Auth.js session + PrjOps `PRF-04`                   | None                                                                                                              | Seven Keys project matrix. Missing session `401`; missing persona `403`. Current production route uses an empty in-memory PrjOps provider.                      |
| `GET`         | `/app/api/data/manager-summary`   | Auth.js session + PrjOps `PRF-03` or DevOps `PRF-G` | Optional paired `periodStart`, `periodEnd` ISO strings                                                            | Manager summary. If either date is absent, both default to the last 28 days.                                                                                    |
| `GET`         | `/app/api/data/projects`          | Auth.js session + any resolved persona              | None                                                                                                              | `{ domain, projects: [{ id, name }] }`.                                                                                                                         |
| `GET`         | `/app/api/data/agent-activity`    | Auth.js session + DevOps `PRF-G`                    | None                                                                                                              | Coding task counts, success rate, recent PRs.                                                                                                                   |
| `GET`         | `/app/api/data/investor-summary`  | Auth.js session + investor persona                  | None                                                                                                              | Investor highlights, KPI table, milestones, risks.                                                                                                              |
| `GET`         | `/app/api/data/timeseries`        | Auth.js session + resolved persona                  | `period=week\|month\|quarter\|half\|year`, `baseDate=YYYY-MM-DD`, optional `persona=executive\|manager\|investor` | Aggregated time-series buckets from `pm_events` and `pm_snapshots`. Invalid period falls back to `month`; invalid base date returns `400`.                      |
| `POST`        | `/app/api/chat`                   | Auth.js session + resolved persona                  | AI SDK `messages` and optional `pageContext`                                                                      | UI message stream with reasoning enabled. `ANTHROPIC_API_KEY` missing returns `503`; LLM daily budget exceeded returns `429`.                                   |

## Error Conversion

`packages/web/src/server/reportData/dataApiSupport.ts` returns known auth errors as their explicit 401/403 JSON messages. Other exceptions are logged server-side and returned as `500 { error: "internal server error" }`.
