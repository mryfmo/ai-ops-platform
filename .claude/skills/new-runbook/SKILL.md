# new-runbook: 運用手順書の作成・追記

## 手順

1. 既存の `runbooks/manual-ops.md` の書式（§番号、表による停止/継続操作の明示、根拠ID参照）を確認する
2. 手順の性質で配置を判断:
   - エージェント停止時の代替操作 → `manual-ops.md` に§追記
   - 定期メンテナンス（purge等）・復旧手順 → 新規ファイル `runbooks/{kebab-case}.md`
3. 各手順に必ず含めるもの:
   - **根拠**: 仕様ID（REQ/SPEC-INT/TH/AC）またはADR番号
   - **前提条件**: 必要な権限・アクセス先（DB接続、GitHub UI等）
   - **手順**: 番号付きステップ。コマンドは実行例をコードブロックで
   - **確認方法**: 手順完了をどう検証するか（SQLクエリ・画面確認等）
   - **監査**: audit_logへの記録要否と記録方法（手動操作はactor=実施者IDで記録）
4. 破壊的操作（DELETE・権限剥奪等）には実行前チェックリストを付ける
