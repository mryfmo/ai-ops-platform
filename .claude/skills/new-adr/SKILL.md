# new-adr: ADR作成

## 手順

1. `docs/adr/` の既存ファイルを確認し、次の連番を採番する（`NNNN-{kebab-case-slug}.md`）
2. 既存ADR（0001〜0004）と同じ以下の書式で作成する:

```markdown
# ADR-NNNN: {決定内容を1文で}

## ステータス

{提案 | 採用 | 廃止（ADR-XXXXにより置換）}

## コンテキスト

{この決定が必要になった背景。元資料・仕様ID・先行ADRへの参照を含める}

## 決定

{何をどうすると決めたか。箇条書きで具体的に}

## 根拠

{なぜ代替案ではなくこれか。検討した代替案と却下理由}

## 影響

{この決定によって変わること・発生する制約・残課題}
```

3. 過去の決定を変更する場合は、旧ADRの本文は書き換えず、新ADRで「置換」を宣言し
   旧ADRのステータスのみ更新する（履歴の保全）
4. 関連する実装がある場合、実装ファイルのヘッダコメントに `ADR-NNNN` を追記する
