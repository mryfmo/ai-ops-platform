# AGMSG-TASK v1 — P005-T10

## Objective

Graph report deliveryの長期監査からrecipient email/subject/body/error payload等PII・秘密情報を除去し、非PII IDで追跡可能にする。

## Work

- `AGT_RPT` とreport delivery failure/success auditsを全追跡し、email、subject、HTML/body、token/clientState、raw Graph error bodyをdetail/loggerから除去。
- 既存recipientId/delivery log key/project/report IDを再利用。新しいハッシュ方式やPII mappingを作らない。
- errorは固定分類/code/statusだけ。外部Error.messageをそのままauditへ入れない。
- positive/failure testsでaudit JSON全体にemail形式、本文marker、subject、secretがないことを検証し、追跡IDは残す。

## Execution boundary

- Executor: `gpt-5.6-sol high`; orchestrator: `codex-gpt56sol-high`.
- Allowed: `packages/devops/src/agents/AGT_RPT.ts`, its direct tests, server report-delivery task/tests only if directly required, and the five P005-T10 orchestration artifacts.
- Forbidden: GraphClient/token/config/subscription/scheduler/Teams manifest changes, schema/dependency changes, tenant/network calls, commit/push/PR, and edits to P005-T05/T06 files.
- Use focused tests while P005-T05 is active. The orchestrator owns final combined CI and acceptance.

## Acceptance

- [ ] success/failure/disabled/retry auditsにPII/secret/bodyなし。
- [ ] recipient/delivery correlationは非PII IDで可能。
- [ ] Graph exception本文を永続化しない。
- [ ] focused/full CI green。
