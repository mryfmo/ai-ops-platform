# AGMSG-TASK v1 — P005-T08

## Objective

Graph retryをHTTP method/idempotencyに適合させ、mail/Teamsの重複送信を防ぎ、正確な成功statusと非PII correlation metadataを実装する。

## Official rules

- Microsoft Graph throttling: valid `Retry-After`を尊重。不正/欠落時だけexponential backoff。
- sendMail success is 202; Teams root/reply success is 201。
- 非冪等mutation POSTの5xx自動再送は禁止（重複送信）。429のみretry。

## Work

- retry helperに明示policy/method semanticsを持たせ、GET/PATCH等安全/条件付き操作とmutation POSTを分離。過剰framework化しない。
- valid nonnegative Retry-Afterを切り詰めず待つ。不正/NaN/負値はjitter backoff。deterministic sleep/clock injectionでテスト。
- sendMailの5xxは再POSTしない。429は指定待機後に上限内retry。
- `saveToSentItems: "true"`を削除（既定true）またはBooleanのみ。successはexact 202。
- root/reply success exact 201。subscription create success exact 201、PATCH successは公式statusに固定。
- requestごとにUUID `client-request-id`; responseのrequest-id/date/statusだけを注入observerへ渡す。URL/body/header/token/email/team raw IDは観測しない。

## Acceptance

- [ ] POST 500で1回のみ、429→valid wait→success。
- [ ] invalid Retry-Afterで即時retryなし、valid >15mを独自capで短縮しない（テストはfake sleep）。
- [ ] exact status違反を成功扱いしない。
- [ ] request ID unique、observer metadata redacted。
- [ ] no string saveToSentItems。
- [ ] focused/full CI green。
