## Acceptance requirements

- Fresh schema applies successfully to PostgreSQL.
- Upgrade preserves fixture rows and JSON content; intentional mismatch rolls back.
- Invalid retention class fails.
- App role can INSERT/SELECT and cannot UPDATE/DELETE.
- Rotation is idempotent, distinguishes `prjops_5y` and `devops_1y`, and cannot target current/future partitions.
- Repeat migration is skipped/idempotent.
- Existing traceability conventions and spec-ID test names remain valid.
- No secret value appears in artifacts.
