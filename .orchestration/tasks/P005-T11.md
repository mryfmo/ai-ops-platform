# AGMSG-TASK v1 — P005-T11

## Objective

外部通信なしで検証可能なsandbox smoke harness骨格を作り、実tenant実行を二重opt-in・allowlist・finally cleanup・redacted evidenceでfail-closedにする。

## Work

- `packages/server/src/tools/graphSmoke.ts` と `graph:smoke` script。
- `--sandbox` と `AIOPS_GRAPH_SMOKE_ENABLED=true` の両方が必須。
- team/channel/sender mailbox/recipient/notification+lifecycle URL/evidence pathを必須化し、P005-T07 access policyと一致しなければtoken前停止。
- operationsをinject可能にし、CI testsはfake Graph/DBのみ。通常test/CIでexternal network不可。
- subscription create後は全途中失敗でもfinallyでDELETEをexactly once。subscription作成前はcleanupしない。
- evidenceはschema version、status、duration、client-request-id、Graph request-id/date/status、DB event count、SHA-256 resource refsのみ。token/secret/body/subject/raw email/team/channel/message/subscription IDは禁止。atomic file write。
- edit/delete APIをapp-onlyで呼ばない。delegated/UI actorがedit/deleteを発生させた後のupdated/deleted受信検証はtenant phaseの別項目として記録。

## Acceptance

- [ ] opt-in/required inputs/allowlist不一致はpre-token fail。
- [ ] each failure pointでcleanup exactly once。
- [ ] redaction testsでraw identifiers/PII/secretなし。
- [ ] fake end-to-end correlation、no-network CI、full gate green。

## External STOP

実tenant smokeはpublic callback、credentials、RSC install/consent、Exchange App RBAC、sandbox IDs、人間/ delegated edit-delete actorが揃うまで実行禁止。

## Result

Five artifacts + AGMSG-RESULT v1.
