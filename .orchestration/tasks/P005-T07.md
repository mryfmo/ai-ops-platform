# AGMSG-TASK v1 — P005-T07

## Objective

Graph送信のteam/mailbox trust boundaryをアプリ側でfail-closedにし、RSC/Exchange設定ミスでも任意送信先へ到達させない。

## Work

- 最小の `GraphAccessPolicy`（normalized allowed team IDs / from mailboxes）をGraphClientへ注入。既存DIを壊さず、production構築時は必須・testsは明示policy。
- Teams root/reply/read/subscription等のteam-scoped external operationはtrim後teamIdをtoken/fetch前照合。少なくとも全送信経路を漏れなく覆う。
- `sendMail` はlowercase/trimしたfromMailboxをtoken/fetch前照合。
- `GRAPH_ALLOWED_TEAM_IDS`, `GRAPH_ALLOWED_FROM_MAILBOXES` をconfigで必須のcomma listとしてparse/重複排除。empty/wildcardは禁止。
- delivery有効時はFROM_MAILBOXがallowlist内、default Teams pairがboth-or-neitherかつteam allowlist内でなければ起動失敗。
- recipient DB由来のallowlist外teamもGraphClientで最終拒否。秘密/本文/宛先をaudit errorへ出さない。

## Acceptance

- [ ] allowlist外/empty team・mailboxはtoken/fetch前拒否。
- [ ] whitespace/case mailbox normalization、team exact normalizationをテスト。
- [ ] empty list/wildcard/invalid defaultsはconfig起動失敗。
- [ ] DB recipientによるboundary bypass不可。
- [ ] focused/full CI green。

## Scope

Shared Graph client/tests、server config/index/direct tests/docsのみ。tenant/Exchange設定は禁止。

## Result

Five artifacts + AGMSG-RESULT v1.
