# P005-T03: Graph card attachment reference and supported actions

## Objective

Make Graph-posted Adaptive Card payloads renderable and remove unsupported `Action.Submit` behavior.

## Model selection

- Worker: `gpt-5.6-sol`, reasoning `high`.
- Reason: approval and incident cards are human-control surfaces; a silently nonfunctional action is a safety defect.

## Primary official evidence

- Microsoft Graph v1.0 card attachment examples put `<attachment id="... "></attachment>` in `body.content` and use the same attachment ID; Graph supports `OpenUrl` card actions and requires bots for other card actions: https://learn.microsoft.com/en-us/graph/api/chatmessage-post?view=graph-rest-1.0
- ADR-0005 already requires Graph cards to use `Action.OpenUrl`, not `Action.Submit`.

## Forbidden actions

- No live Graph/Bot/consent/schema/dependency/commit/push/PR action.
- Do not introduce a Bot Framework endpoint.
- Do not invent a callback URL or keep `Action.Submit` as a fallback.

## Single tasks

1. Add failing tests proving card payload `body.content` references the exact attachment ID for both root message and reply paths.
2. Make GraphClient reject any nonempty legacy `card.actions` before token/fetch and emit only `Action.OpenUrl` actions.
3. Update approval card input to require an explicit reviewed decision URL and render one OpenUrl action to that human decision surface.
4. Update Sev1 candidate card to use the already-created GitHub issue URL as its human review OpenUrl; remove unsupported submit buttons.
5. Add adversarial tests that no serialized Graph payload contains `Action.Submit`, nonempty legacy actions fail before fetch, and missing/blank required decision URL fails closed.

## Acceptance checks

- Root and reply payloads use matching attachment references.
- `rg -n 'Action.Submit' packages/shared/src/clients/graphClient.ts` has no production match.
- Approval/incident cards retain a human review path using explicit URLs.
- Focused tests, affected package typechecks, formatter, and `git diff --check` pass.
