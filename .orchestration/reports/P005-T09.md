# P005-T09 Report

Status: ready_for_review

## Outcome

- Replaced the direct OAuth POST and custom TTL cache with `@azure/msal-node` 5.4.0 `ConfidentialClientApplication`.
- Added a narrow injectable `acquireTokenByClientCredential` contract for networkless tests; production bootstrap and the subscription CLI now use `createMsalGraphTokenProvider`.
- Fixed every request to `https://graph.microsoft.com/.default`; authority is derived only from configured tenant ID, with no caller-supplied scope or authority.
- Delegated application caching, expiry offset, and proactive refresh to MSAL. The wrapper retains only one in-flight Promise to coalesce concurrent calls and clears it on success or failure.
- Null results, empty/blank/whitespace-surrounded tokens, null/invalid/expired expiry, and SDK failures all fail closed with the exact fixed `E-AUTH01: Graph token acquisition failed` message. SDK errors, response data, secrets, and tokens are not propagated or logged.
