# P005-T08 Report

Status: ready_for_review

## Outcome

- `fetchWithBackoff` now distinguishes idempotent work from non-idempotent POST. Mutation POST retries only 429; GET/PATCH/DELETE retain bounded 429/5xx retry.
- Valid decimal `Retry-After` seconds are honored without the local 15-minute cap. Missing, negative, exponent, hex, fraction, NaN, and unsafe-overflow values use capped jitter; initial fallback delay is constrained before use.
- Mail succeeds only on 202; Teams root/reply and subscription create only on 201; subscription PATCH and GET only on 200; cleanup DELETE only on 204, with 404 retained as idempotent cleanup success.
- Removed string `saveToSentItems`; Graph's default behavior is used.
- Every HTTP attempt receives a unique UUID `client-request-id`, including retries with a faulty injected provider. Observer metadata contains only client UUID, validated response UUID or null, canonical HTTP date or null, and status.
- Observer failures are isolated and cannot fail a completed request or cause duplicate delivery.

## Cycle 1

All five review findings were covered by red-first tests: observer non-interference, faulty-provider retry uniqueness and correlation sanitization, exact GET/DELETE statuses, unsafe Retry-After forms, and capped fallback jitter.

## XHigh escalation

The three remaining findings were reproduced together as exactly three focused failures, then closed without changing the accepted Graph status/retry or P005-T07 continuation behavior:

- Async observer results are fire-and-forget with an immediate rejection handler. Both synchronous throws and rejected Promises are consumed; neither changes the completed HTTP result or triggers a resend.
- Removed the unbounded `issuedRequestIds` history. A fixed 48-bit per-client sequence is encoded into the UUID tail, keeping constant storage and valid unique IDs across a 10,000-attempt faulty-provider stress test.
- Native sleep divides a valid server delay above `2_147_483_647ms` into safe sequential timer chunks. An injected sleep still receives the exact uncapped total once for deterministic tests.

## Scope

The xhigh escalation changed only the shared Graph client, `graphClient.test.ts`, and the five P005-T08 artifacts. Accepted P005-T01 through T07/T10 worktree changes were preserved. No tenant/network action, dependency/schema change, commit, push, or PR was performed.
