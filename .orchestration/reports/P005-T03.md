# P005-T03 Report

Status: ready_for_review

## Outcome

- Added one shared Adaptive Card attachment builder used by root and reply Graph message paths.
- Both paths now place `<attachment id="1"></attachment>` in `body.content` and use the same attachment ID.
- Nonempty legacy `card.actions` now fail before token acquisition or fetch; serialized cards emit only `Action.OpenUrl` actions.
- Approval packages now require a reviewed `decisionUrl`, reject missing/empty/whitespace values, and expose one human decision OpenUrl.
- Sev1 candidate cards now link to the already-created GitHub issue for human review and contain no unsupported submit buttons.
- Revision: reply cards always emit `body.contentType=html`; text caller content is HTML-escaped before the attachment reference, while HTML caller content is preserved.
- Revision: every OpenUrl requires a nonblank title and absolute HTTPS URL before token/fetch. CHG rejects unsafe decision URLs and INC rejects unsafe GitHub issue URLs before Graph delivery.
- Independent P2 revision (`019f4eaa-8711-7632-8125-c65799cca0e6`): root and reply paths normalize Teams IDs once, then use the same trimmed values for validation and URL encoding. Reply also rejects blank `parentMessageId` before auth/fetch.

## Scope

Only the allowed shared Graph client/tests, DevOps CHG/INC agents and their direct test were changed. Accepted P005-T01/T02 changes were preserved. No Bot Framework endpoint or callback URL was introduced.

## External actions

No live Graph, Teams, Bot, consent, schema, dependency, commit, push, or PR action occurred.
