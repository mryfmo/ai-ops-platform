# A047 Phase 1 specification disposition matrix

## Method

This matrix inventories every specification identifier directly cited by the dormant AGT-02/AGT-04 implementation and dedicated tests, plus child acceptance/external-contract identifiers needed to avoid hiding a lost behavior behind a parent REQ. A row is `satisfied` only when a runtime-reachable implementation and behavior evidence exist. Export-only modules, templates called only by tests, and pure helpers with no live caller are not satisfaction evidence.

Runtime searches found no caller of `ingestOne`, `structureFreeText`, `generateProfileNarratives`, or `generateExecutiveReport` outside their dormant modules/tests. The live report route is `.github/workflows/report-generation.yml:50-112` → `packages/shared/src/reporting/*` → `packages/server/src/http/routes/reportIngest.ts:38-105` → `packages/server/src/scheduler/tasks/reportDeliveryTask.ts:150-192`. The live Teams path stores authorized/sanitized channel messages at `packages/server/src/scheduler/tasks/channelPollingTask.ts:257-276` and interprets only GitHub/coding intents at `packages/server/src/lib/freeTextIntent.ts:15-67`; it does not structure status reports.

The two tables below preserve the initial Phase 1 evidence and classifications that caused the blocked gate. The **post-ruling final disposition** following them is authoritative for Phase 2/3: it distinguishes a preserved pure contract from a runtime product obligation and never treats a test-only contract as proof of live wiring.

## Post-ruling final disposition

The orchestrator ruled that ADR-0012 standardizes the generation mechanism only; it does not supersede the stakeholder profile contracts. D-15 owns the remaining product-scope decision. Full status ingest is outside A047 and registered as A054. A047 therefore preserves only the ruled pure contracts and removes only orchestration proven to have zero runtime callers.
