# P005-T07 Result

Status: ready for review.

Implemented a fail-closed `GraphAccessPolicy` in `GraphClient`. Team IDs are trimmed and matched case-sensitively; sender mailboxes are trimmed/lowercased. Adaptive-card send, message read/delta/replies, subscription create/renew/delete, and mail send all reject outside-policy values before token acquisition or fetch. Errors contain only fixed classification text.

Server config now requires `GRAPH_ALLOWED_TEAM_IDS` and `GRAPH_ALLOWED_FROM_MAILBOXES`, parses comma lists with deduplication, rejects empty/wildcard values, validates mailbox syntax, and validates enabled delivery/default destinations. Resident server and subscription CLI inject the parsed policy. Subscription renewal, lifecycle reauthorization, and replacement cleanup carry the ledger `teamId` into the Graph boundary.

Tests were added first and observed failing before implementation. Direct tests cover outside/empty/case-sensitive team IDs, mailbox whitespace/case normalization, DB-derived team bypass, production CLI policy injection, lifecycle caller propagation, invalid config/defaults, and pre-auth/pre-fetch rejection.

No tenant, network Graph operation, dependency/schema change, commit, push, or PR was performed. Concurrent P005-T05/T06/T10 behavior and files were preserved except the explicitly authorized minimal T05 interfaces/callers/tests and shared/config/index/docs/CLI lines.

Full monorepo CI remains orchestrator-owned because the worktree contains concurrent tasks. Shared and server package-wide validation is green; see validation artifact.

## Cycle 1 revision

The original result did not cover attacker-controlled Graph continuation URLs. `getChannelMessagesDelta` now validates the initial persisted delta URL, every `@odata.nextLink`, and the returned `@odata.deltaLink` before fetch or persistence. URLs must have no surrounding whitespace, credentials, or fragment and must use the configured Graph origin plus the exact normalized team/channel delta path. Different/disallowed teams, external origins, and paths that normalize from noncanonical input are rejected with a fixed error.

The same bearer-exfiltration pattern existed in reply pagination, so `listMessageReplies` now applies the same origin/resource-path guard to every nextLink. Adversarial tests prove no second fetch is made to external or cross-team URLs. `runbooks/e2e-real-environment.md` now includes both mandatory Graph allowlists and their normalization/startup constraints.
