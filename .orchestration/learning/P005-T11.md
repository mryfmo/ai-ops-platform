# P005-T11 Learning Triage

Decision: no new promoted rule.

Reusable observations already belong to the existing Graph learning record:

- A smoke runner must enforce opt-in at both CLI parsing and callable execution boundaries; a parsed marker alone can be forged by direct callers.
- Subscription cleanup ownership starts when create returns, before response-field validation, so later validation failures still trigger one cleanup attempt.
- Redacted failure evidence needs its own adversarial test because success-only evidence tests do not cover exception text or partial resource state.
- Security-sensitive output paths need an exact real root, direct-child restriction, symlink and preexistence checks, and no-overwrite publication; canonical string checks alone do not close filesystem races.
- A numeric DB event count is not proof of end-to-end delivery unless the query contract receives the exact Graph subscription, message, and request correlation identifiers.

These observations are captured in P005-T11 tests and should be considered for the existing Graph plan/tests; this worker did not edit `.agents`.
