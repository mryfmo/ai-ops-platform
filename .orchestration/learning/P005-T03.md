# P005-T03 Learning Triage

## Reusable learning

- Graph Adaptive Card attachments are a two-part contract: the message body must reference the exact attachment ID, not merely include an `attachments` array.
- Human-control cards must expose a supported reviewed URL and reject unsupported action transports before credentials or network work begins.
- Attachment markup requires an HTML message body; text content must be escaped before converting the body to HTML.
- URL-bearing human controls need validation at both the reusable transport boundary and the domain caller boundary so mocks cannot bypass safety behavior.
- Normalize external identifiers once and reuse the normalized value for both validation and encoding; validating a derived value while sending the raw value defeats the boundary check.

## Disposition

- Retained as task learning only; no rule was promoted and no registry state changed.
- Promote only if another Graph card integration repeats the same attachment/action failure mode.
