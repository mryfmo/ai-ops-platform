# P005-T02 Learning Triage

## Reusable learning

- For webhook dedupe, absence of an optional provider identity/version is not evidence of equality. Disable dedupe rather than synthesizing a key from coarser resource identity.
- A version fallback must include the full provider context and change type; otherwise independent resources or lifecycle transitions can collide.

## Disposition

- Retained as task learning only; no rule was promoted and no registry state was changed.
- This can become a rule candidate if another webhook integration presents the same optional-identity failure mode.
