# P005-T07 Learning Triage

Candidate reusable rule: a team-scoped Graph subscription ID is not sufficient authorization context. Renew/delete APIs must carry the ledger team ID to the same pre-auth allowlist guard used by create/read/send operations; otherwise an allowlisted subscription API permission can bypass destination policy.

Validated by direct GraphClient pre-token/pre-fetch tests and server caller propagation tests for scheduled renewal, lifecycle reauthorization, recovery renewal, and orphan cleanup.

Apply to: future Graph resource operations and tests. Keep as a candidate for orchestrator review; no skill/rule promotion was performed.

Cycle 1 candidate: OAuth-bearing pagination URLs are trust-boundary input even when returned by the expected API. Validate every initial/next/delta URL against both the configured origin and the exact authorized resource path before fetch or persistence; origin-only checks do not prevent cross-team access. This was validated for delta and reply pagination, including noncanonical paths that the URL parser would otherwise normalize.
