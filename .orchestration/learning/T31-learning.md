# T31 Learning Triage

## Reusable Observations

1. A remediation plan needs an explicit STOP branch wherever owner/platform/legal decisions are prerequisites; otherwise executors silently decide policy.
2. Repository verification gates and production real-environment evidence are different ledgers. The former can unblock later implementation; only the latter can unblock go-live.
3. One-to-one finding coverage is necessary but insufficient: phase membership also needs a no-gap/no-duplicate union check.
4. Fixed evidence directories make acceptance receipts reviewable without letting executors invent storage locations.
5. Severity cannot override dependency truth: a CRITICAL implementation whose cited requirements are undefined must follow canonical reconstruction and owner approval, even when an earlier task brief called for all CRITICAL work first.
6. Finding coverage must name its audit snapshot; a later audit needs an explicit extension procedure rather than inheriting an obsolete completeness claim.
