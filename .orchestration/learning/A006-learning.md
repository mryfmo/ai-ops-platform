# A006 Learning

## Candidate reusable learning

An acceptance manifest must not use its own fields as the trust root. Pin the governing document to an immutable commit/blob/content hash, derive artifacts and file modes from Git objects, derive dependencies from the pinned policy, and keep the test's golden task universe independent from implementation constants.

Development placeholders can be permitted without weakening production criteria by requiring a tracked operator decision and emitting an unavoidable DEV-TRUST warning. A manifest-only reviewer, approver, environment result, path, or hash must remain insufficient.
